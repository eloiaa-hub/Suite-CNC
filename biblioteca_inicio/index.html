📚 Biblioteca de inicio

40 ejercicios para el Calcador, en 4 niveles y de menos a más dentro de cada nivel · Suite CNC

Cómo se usa
  1. Todos de una vez: descarga Biblioteca_de_inicio.json y, en el Calcador, abre 📚 Biblioteca → «Importar archivos…». Quedan en la carpeta Biblioteca de inicio, con las etiquetas Inicio y Nivel 1 … Nivel 4.
  2. Uno a uno: pulsa un ejercicio para descargar su JSON y ábrelo en el Calcador como cualquier proyecto. (Si ya has importado el archivo de todos, no hace falta: saldrían dos veces.)
  3. Para imprimir: cada nivel tiene sus hojas de ejercicio y sus soluciones en PDF.
